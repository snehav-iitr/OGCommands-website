## Alias

`..convert`

## Overview

Convert to JPEG, PNG, HEIC, TIFF, GIF, BMP, or WebP (libwebp). Choose the target format in Settings first.

## Steps

1. Configure options in **Commands & Settings → Convert Image Format** if needed.
2. Select files in Finder.
3. Press **⌥Space**, type `..convert`, press **Return**.
4. Review results and reveal outputs in Finder.

## Safety

Writes copies (except duplicate trash action). Originals stay put for write commands.

See the [command library entry](/commands/convert) for settings, formats, and limitations.
