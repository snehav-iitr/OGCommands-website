## Finder Automation (recommended)

Needed so OG⌘ can read your Finder selection.

- Prompt appears on first use
- Re-check from **Commands & Settings → General → Check Finder Automation**

## Accessibility (optional)

Only required if you enable typed `..command` capture while Finder is focused.

## Privacy note

Permissions are for local automation. Command processing stays on your Mac. See the [Privacy Policy](/privacy).
