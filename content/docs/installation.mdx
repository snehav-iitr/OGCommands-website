## Requirements

- **macOS 14 Sonoma** or later
- Apple silicon or Intel Mac

## Download the app

1. Open the [Download](/download) page.
2. Download `OG-Commands-0.1.0-macos.zip`.
3. Unzip the file.
4. Open **OG Commands**.
5. If macOS warns you, right-click the app → **Open**.

This build is **ad-hoc signed only** (not Developer ID / not notarized). See [Download](/download) for the SHA-256 and signing disclosure.

## First launch

1. Look for the OG⌘ icon in the menu bar.
2. Select a few images in Finder.
3. Press **⌥Space**.
4. Type `..resize` and press **Return**.
5. Find the copies in `~/Downloads/OG Commands` (default).

## Permissions you may see

| Permission | Why |
|---|---|
| **Automation → Finder** | Read the files you selected in Finder |
| **Accessibility** (optional) | Typed `..command` capture while Finder is focused |

You can change these later in System Settings and in **Commands & Settings → General**.

## Build from source (optional)

Maintainers can package from the private app repository:

```bash
chmod +x scripts/package-app.sh
./scripts/package-app.sh debug
open "dist/OG Commands.app"
```

The script builds the Swift app, creates `dist/OG Commands.app`, and ad-hoc signs the bundle.
