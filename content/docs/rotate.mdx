## Alias

`..rotate`

## Overview

Rotate by 90°, 180°, or 270° clockwise or counter-clockwise.

## Steps

1. Configure options in **Commands & Settings → Rotate Images** if needed.
2. Select files in Finder.
3. Press **⌥Space**, type `..rotate`, press **Return**.
4. Review results and reveal outputs in Finder.

## Safety

Writes copies (except duplicate trash action). Originals stay put for write commands.

See the [command library entry](/commands/rotate) for settings, formats, and limitations.
