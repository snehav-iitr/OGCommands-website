### Does OG⌘ modify my originals?

Write commands create copies. `..duplicate` can move extras to Trash only when that action is enabled and confirmed.

### Is there a Windows app?

Not yet. Shared command contracts exist for a future Tauri + Rust build. This website does not offer a Windows download.

### Is the app free?

There is no payments integration in this product or website yet.

### Is ..removebg a paid API?

No. It uses on-device ONNX Runtime with Apache-2.0 U²-Net family weights after an optional, explicit download.

### Why ⌥Space instead of Space?

So Space still types spaces and Finder Quick Look still works.
