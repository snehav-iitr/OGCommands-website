Open **Commands & Settings…** from the menu bar icon.

## Per-command settings

Select a command in the Library sidebar. Examples:

- **Compress** — quality, output format, suffix
- **Resize** — max width/height
- **Convert** — target format (including WebP)
- **Crop** — aspect ratio or inset %
- **Rotate** — degrees and direction
- **PDF** — page size and filename
- **Duplicate** — match mode and trash action
- **Gather** — subfolder and conflict policy
- **Remove Background** — model choice and threshold

## Enable / disable in launcher

Each command has **Enabled in launcher**. Disabled commands stay in Settings but won’t appear in search.
