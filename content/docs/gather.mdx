## Alias

`..gather`

## Overview

Copy any selected files into a Gathered subfolder. Sources are never moved.

## Steps

1. Configure options in **Commands & Settings → Gather Files** if needed.
2. Select files in Finder.
3. Press **⌥Space**, type `..gather`, press **Return**.
4. Review results and reveal outputs in Finder.

## Safety

Writes copies (except duplicate trash action). Originals stay put for write commands.

See the [command library entry](/commands/gather) for settings, formats, and limitations.
