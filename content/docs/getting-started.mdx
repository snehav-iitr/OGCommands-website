## Your first command

1. Open **OG Commands** (menu bar icon).
2. Select a few images in Finder.
3. Press **⌥Space** (Option + Space).
4. Type `..resize` and press **Return**.
5. Find the copies in `~/Downloads/OG Commands` (default).

That’s the loop: **Select → Open OG⌘ → Run command**.

## Change settings before you run

Right-click the menu bar icon → **Commands & Settings…**

- Pick a command in the Library sidebar
- Adjust quality, sizes, formats, crop ratios, and more
- Those values are used the next time you run the alias from the launcher

## Handy examples

| Goal | Type this |
|---|---|
| Smaller photos | `..compress` |
| Fit a max size | `..resize` |
| Transparent PNG | `..removebg` |
| One PDF from images | `..pdf` |
| Collect mixed files | `..gather` |
