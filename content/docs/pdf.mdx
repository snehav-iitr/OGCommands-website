## Alias

`..pdf`

## Overview

Combine selected images into one PDF. Page size: fit image, A4, or Letter.

## Steps

1. Configure options in **Commands & Settings → Images to PDF** if needed.
2. Select files in Finder.
3. Press **⌥Space**, type `..pdf`, press **Return**.
4. Review results and reveal outputs in Finder.

## Safety

Writes copies (except duplicate trash action). Originals stay put for write commands.

See the [command library entry](/commands/pdf) for settings, formats, and limitations.
