**OG⌘ Commands** is a native macOS productivity app from **OG**. It lives in the menu bar and opens a typing panel with **⌥Space** so you can run predefined file commands without hunting through dialogs.

## What it does today

- Compress, resize, convert, crop, and rotate images
- Combine images into a PDF
- Find exact duplicate images
- Gather mixed files into one folder
- Remove backgrounds offline with an on-device ONNX model (`..removebg`)

## Design principles

1. **Copies by default** — originals are not overwritten.
2. **Local processing** — no paid cloud APIs for command execution.
3. **Settings first** — configure in Commands & Settings, then run from the launcher.
4. **Honest status** — Windows is planned via shared contracts, but not released.

## What it is not

- Not an AI chat that invents new commands
- Not a Windows app (yet)
- Not notarized by default — see the Download page for the current signing disclosure
