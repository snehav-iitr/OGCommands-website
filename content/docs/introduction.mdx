**OG⌘ Commands** is a macOS menu-bar app. Press **⌥Space**, type a short command, and get file results without jumping between tools.

## What it does today

- Compress, resize, convert, crop, and rotate images
- Combine images into a PDF
- Find exact duplicate images
- Gather mixed files into one folder
- Remove backgrounds on your Mac (`..removebg`)

## How to think about it

1. **Copies by default** — originals stay put.
2. **Runs on your Mac** — file work stays local.
3. **Set once, run often** — configure in Commands & Settings, then use the launcher.
4. **macOS first** — Windows is not available yet.

## What it is not

- Not a chat bot that invents new commands
- Not a Windows app yet
- Not notarized by default — see [Download](/download) for the current signing disclosure
