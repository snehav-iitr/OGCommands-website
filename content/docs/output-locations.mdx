## Default folder

`~/Downloads/OG Commands`

Change it in **Commands & Settings → General → Choose Output Folder…**

## Naming

Most image commands write:

`{basename}{suffix}.{ext}`

If the file already exists, OG⌘ increments: `name-2.ext`, `name-3.ext`, …

## Safety

- Originals are not overwritten by write commands
- `..gather` copies only
- `..duplicate` can move extras to Trash only when that action is enabled and confirmed
