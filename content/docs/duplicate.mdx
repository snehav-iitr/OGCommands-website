## Alias

`..duplicate`

## Overview

Exact byte or pixel matching. Report-only by default; Trash requires confirmation.

## Steps

1. Configure options in **Commands & Settings → Find Duplicate Images** if needed.
2. Select files in Finder.
3. Press **⌥Space**, type `..duplicate`, press **Return**.
4. Review results and reveal outputs in Finder.

## Safety

Writes copies (except duplicate trash action). Originals stay put for write commands.

See the [command library entry](/commands/duplicate) for settings, formats, and limitations.
