## Alias

`..removebg`

## Overview

On-device ONNX background removal. Default model u2netp. Download only after you approve.

## Steps

1. Configure options in **Commands & Settings → Remove Background** if needed.
2. Select files in Finder.
3. Press **⌥Space**, type `..removebg`, press **Return**.
4. Review results and reveal outputs in Finder.

## Safety

Writes copies (except duplicate trash action). Originals stay put for write commands.

See the [command library entry](/commands/removebg) for settings, formats, and limitations.
