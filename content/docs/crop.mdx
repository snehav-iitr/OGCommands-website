## Alias

`..crop`

## Overview

Center crop to aspect ratios or inset percentages. V1 is center-only.

## Steps

1. Configure options in **Commands & Settings → Crop Images** if needed.
2. Select files in Finder.
3. Press **⌥Space**, type `..crop`, press **Return**.
4. Review results and reveal outputs in Finder.

## Safety

Writes copies (except duplicate trash action). Originals stay put for write commands.

See the [command library entry](/commands/crop) for settings, formats, and limitations.
