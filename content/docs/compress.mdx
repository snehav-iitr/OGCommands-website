## Alias

`..compress`

## Overview

Create optimized compressed copies. Set quality in Settings, then run from the launcher.

## Steps

1. Configure options in **Commands & Settings → Compress Images** if needed.
2. Select files in Finder.
3. Press **⌥Space**, type `..compress`, press **Return**.
4. Review results and reveal outputs in Finder.

## Safety

Writes copies (except duplicate trash action). Originals stay put for write commands.

See the [command library entry](/commands/compress) for settings, formats, and limitations.
