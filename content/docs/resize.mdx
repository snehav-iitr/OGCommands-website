## Alias

`..resize`

## Overview

Resize while preserving aspect ratio. Defaults max 1920×1080; images are not upscaled beyond bounds.

## Steps

1. Configure options in **Commands & Settings → Resize Images** if needed.
2. Select files in Finder.
3. Press **⌥Space**, type `..resize`, press **Return**.
4. Review results and reveal outputs in Finder.

## Safety

Writes copies (except duplicate trash action). Originals stay put for write commands.

See the [command library entry](/commands/resize) for settings, formats, and limitations.
