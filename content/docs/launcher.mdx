The launcher is a compact typing panel — not a settings form.

## Default hotkey

**⌥Space** (Option + Space)

Plain Space is intentionally not used, so normal typing and Finder Quick Look keep working.

## What you see

- Brand mark and “OG Commands”
- A text field — type `..compress`, `..pdf`, etc.
- A filtered list of commands
- Status text about selected files

Press **Return** to run the matched command immediately.

## Optional: type in Finder

In **Commands & Settings → General**, you can enable “Also listen for ..commands in Finder”. This requires **Accessibility** permission and is **off by default**.
