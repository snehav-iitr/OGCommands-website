## Preferred: Finder selection

1. Select one or more files in Finder.
2. Open the launcher with ⌥Space.
3. Run a command.

OG⌘ uses **Finder Automation** to read the selection. Grant access when macOS prompts, or open Automation settings from **Commands & Settings → General**.

## Fallback: file picker

If nothing is selected, OG⌘ opens a file picker so you can choose files manually.

## Tips

- For `..gather`, select **files**, not folders.
- For `..duplicate`, select at least **two** images.
- Selection order matters for `..pdf` page order.
